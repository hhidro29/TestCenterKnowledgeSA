### A. Ketentuan fisik dan medis per sekolah kedinasan

#### IPDN (Institut Pemerintahan Dalam Negeri)

| Aspek | Ketentuan |
|---|---|
| Tinggi badan | Laki-laki minimal 160 cm; perempuan minimal 155 cm |
| Gigi | Gigi hilang/berlubang mengurangi poin |
| Mata — buta warna | Tidak boleh buta warna parsial maupun total |
| Mata — minus/plus/silinder | Tidak boleh minus; jika ada dinyatakan gugur |
| Tulang | Tidak boleh ada tulang tumbuh |
| Bekas luka | Luka yang masih terasa sakit dapat menggugurkan |
| Varises | Ringan–sedang masih bisa ditoleransi |
| Keloid | Tergantung jumlah dan ukuran |
| Kaki X/O | Toleransi maksimal 7 cm |
| Varikokel | Mengurangi poin; perlu konsultasi medis |
| Flatfoot | Flatfoot total tidak diperbolehkan |
| Cadel/gagap | Ringan ditoleransi |
| Epilepsi | Semua jenis menggugurkan |
| Bekas fraktur | Masih diperbolehkan; jika masih sakit dan mengganggu, mengurangi poin |
| Stretch marks | Tidak berpengaruh signifikan |

#### PKN STAN (Politeknik Keuangan Negara — Sekolah Tinggi Akuntansi Negara)

| Aspek | Ketentuan |
|---|---|
| Tinggi badan | Tidak ada ketentuan |
| Gigi | Gigi tidak rapi, berlubang, atau ada gigi hilang masih aman; sebaiknya diperbaiki |
| Mata — buta warna | Tidak ada ketentuan |
| Mata — minus/plus/silinder | Minus/silinder diperbolehkan |
| Tulang | Masih aman jika ada tulang tumbuh |
| Bekas luka | Diperbolehkan |
| Varises | Ringan–sedang masih bisa diterima |
| Keloid | Tidak terlalu berpengaruh |
| Kaki X/O | Toleransi maksimal 7 cm |
| Varikokel | Tidak berpengaruh |
| Flatfoot | Flatfoot total tidak diperbolehkan |
| Cadel/gagap | Cadel ringan ditoleransi |
| Epilepsi | Semua jenis menggugurkan |
| Bekas fraktur | Masih diperbolehkan |
| Stretch marks | Tidak berpengaruh |
